## 🎥 &nbsp;Behind the Camera

<img src="https://skillicons.dev/icons?i=nextjs,react,ts,tailwind,threejs,vercel&theme=dark" alt="Next.js, React, TypeScript, Tailwind, Three.js, Vercel" />

<br><br>

| Layer | Craft |
|:--|:--|
| **Framework** | Next.js 14 · App Router · TypeScript |
| **Styling** | Tailwind CSS · CSS variables for scene lighting |
| **Motion** | GSAP scroll choreography · horizontal pinning |
| **3D** | Three.js backdrop and skill core |
| **Sound** | Custom audio hook with a generated drone fallback |

## 🎞️ &nbsp;Roll Camera

```bash
git clone https://github.com/hux-ain/muhammad-ul-hussain.git
cd muhammad-ul-hussain
npm install
npm run dev
```

Open **[localhost:3000](http://localhost:3000)**. For a production cut: `npm run build && npm start`.

<br>

## ✂️ &nbsp;Director's Cut

| To change | Edit |
|:--|:--|
| Name, links, projects, certificates | `data/portfolio.ts` |
| Scene brightness | `--dim-*` variables in `app/globals.css` |
| Soundtrack | `public/audio/cinematic.mp3` |
| Videos & posters | `public/` |

<details>
<summary><b>📁 &nbsp;Project structure</b></summary>
<br>

```
app/              layout, global styles, lighting variables
components/
  ├─ scenes/      one file per scene
  ├─ book/        the About book
  └─ three/       3D backdrop and skill core
data/             portfolio.ts — the script
hooks/            audio, horizontal pin, in-view
lib/              scroll store
public/           videos, posters, audio
```

</details>
